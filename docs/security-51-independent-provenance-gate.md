# SECURITY-51 — Independent provenance verification gate (offline)

## Implemented
An isolated synthetic test models a publisher Ed25519 signature and a *separate* witness Ed25519 signature that binds the publisher's observation hash, publisher signature hash and independent observed-at timestamp. The gate checks source/game identity, both configured public keys, evidence chain, witness observation before the prediction cutoff, missing evidence, tampering, wrong keys, cross-game replay and backdated publisher claims observed after cutoff.

## Explicit limitations
Both keys are freshly generated by the same offline test process. They represent logically separate parties, **not independently verified real-world institutions**. The test does not fetch or verify any real NHL or goalie-provider record, does not establish trusted clock authority or independently anchored timestamps, and does not prove actual publisher identity. Actual source approval, trusted key distribution/pinning, external timestamp/witness infrastructure, archived signed evidence and end-to-end CORE43-CAL planner integration remain **NOT VERIFIED**. No production release is authorized.
