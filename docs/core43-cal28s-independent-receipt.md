# CAL-28S — independently signed offline archive receipt

A new isolated, offline Ed25519 receipt verifier requires an externally pinned auditor public key and binds an auditor identity, archive store ID, object version and archive digest to a deterministic signed message. It rejects mismatched digest, substituted object version, malformed fields, non-independent auditor identifiers, invalid signatures and unrecognized key types. Tests use freshly generated synthetic keys only.

**Trust boundary:** The verifier checks only a cryptographic signature over a claimed receipt. It does not query a real storage provider, establish that an auditor is truly independent, verify retention or effective permissions, prove the object version exists, or attest that the bytes are immutable. A passing receipt explicitly returns `trusted:false`. CAL-28R policy booleans remain untrusted self-assertions. The verifier is not wired into receiver pin advancement. External credential provisioning, authenticated provider metadata, real WORM compliance validation, independent principal audits and operational signoff remain blockers. No production changes, Supabase writes, merges or deployment.
