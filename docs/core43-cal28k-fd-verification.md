# CAL-28K — descriptor-bound evidence reads

CAL-18B verification now opens archive evidence with `O_RDONLY | O_NOFOLLOW | O_NONBLOCK`, checks the opened file descriptor with `fstatSync` before and after reading, requires regular files and one hard link, and checks stable inode, size, mtime and ctime. CAL-28J link/tamper regression tests remain and additional tests reject hardlinked manifests and directories masquerading as evidence files.

**Security limitations:** The parent archive directory is still resolved by pathname; an attacker able to rename or replace archive directories can race traversal. A malicious concurrent writer may mutate data between reads, including in-place replacement that cannot be reliably excluded by metadata checks. Writer pin lock does not freeze the archive. File descriptors mitigate file symlink substitution but are not an immutable snapshot or proof of adversarial race resistance. Follow up with trusted read-only snapshot or dirfd/openat-style containment and adversarial concurrent mutation tests. Test TSA is synthetic; independent authority and real-game start still unproven. No production changes, Supabase writes, merge or deployment.
