# CAL-28Z — offline full-history consistency verification

CAL-28Z compares two differently sized, fully signed CAL-28W rotation histories using the same genesis checkpoint. It verifies each CAL-28X witness quorum and every signed history entry, then checks that the older history is an exact prefix of the newer history, including signatures. It requires distinct observer IDs and an additional witness ID in the newer view. Ten synthetic tests cover valid extension, alternate signed prefixes, rollback, changed genesis, forgery, unknown witnesses, duplicate observers and witness failures.

This is a **bounded full-replay proof**, not a compact Merkle consistency proof. Both complete histories are supplied, and CAL-28W caps replay at 64 entries. The genesis, signing authority and witness keys remain caller supplied, so external independence and global consistency are not established; results always return `trusted:false`. A real deployment requires pinned independent genesis and key roots, published witnessed checkpoints, consistency across hosts and a scalable authenticated append-only log. No production pin integration, Supabase writes, live dry-run, merge, deployment or CORE 4.2 modification.
