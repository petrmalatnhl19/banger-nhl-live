# CAL-28Y — offline cross-view checkpoint consistency

The verifier compares two separately supplied CAL-28X-signed checkpoint views. It verifies each chain and witness quorum, requires distinct observer IDs and at least one additional witness ID in the second view, and rejects conflicting heads at the same sequence. Different sequence numbers fail closed pending a formal append-only consistency proof. Nine synthetic tests exercise forks, duplicate observers, identical witness sets, invalid signatures, tampering, unknown witnesses, extra trust fields and different sequence numbers.

**Limitations:** Distinct names do not prove independent hosts. The checkpoint roots, authority and witness public keys are caller supplied; a coordinated attacker can replace them. Identical checkpoints do not prove absence of hidden forks or globally consistent publication. Always returns `trusted:false`. Real deployment needs independently authenticated observers and witnesses, gossip and persistent checkpoints, monotonic log consistency proofs and evidence of key custody. No live network calls, no Supabase writes, no pin integration, no production CORE 4.2 changes, no merges or deployments.
